# Ride Booking History System

## Overview

This project implements a Ride Booking History System using a Linked List in Java. It simulates backend ride logs similar to those used in ride-hailing platforms.

---

## Features

* Add a new ride
* Delete the most recent ride
* Display all rides
* Search rides by pickup or drop location
* Reverse ride history

---

## Tech Stack

* Language: Java
* Concepts: Linked List, Object-Oriented Programming

---

## Core Concepts

* Singly Linked List implementation
* Dynamic memory allocation
* Node traversal and manipulation
* Encapsulation in Java
* Reverse algorithm using three-pointer technique
